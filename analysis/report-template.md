## 写作规范

| 规则 | 正确写法 | 错误写法 |
|------|---------|---------|
| 金额单位用**万元**或完整数字+元，禁止用 K/M | `52万元` 或 `520,006元` | `520K` `0.52M` |
| 数字范围用**「到」**或**「～」**（全角波浪线），禁止用 `~`（半角，会被 Markdown 渲染为删除线） | `10万到15万元` 或 `10～15万元` | `100~150K` |
| 百分比/时间范围同上 | `3到6个月` 或 `3～6个月` | `3~6个月` |
| 收益/亏损用加减号+元表达 | `+96,880元（+40.67%）` | `+96880元` |
| 操作类型统一用规定 emoji 前缀（见下方行动指令规范） | `✅ 立即买入` | `可以买入` |

---

## 报告结构概览

报告分**两大部分**，以 `---` 分隔：

1. **行动指令**（第一章）— 打开报告第一眼就能看到要做什么
2. **分析支撑**（第二章起）— 详细数据、市场环境、配置分析，为行动提供依据
