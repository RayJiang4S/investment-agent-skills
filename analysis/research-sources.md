### 冲突对投资决策的影响判定

| 冲突阶段 | 市场表现规律 | 操作原则 |
|---------|-----------|---------|
| 突发爆发（前1到2周） | 恐慌性下跌，VIX飙升 | **不卖**。恐慌期卖出大概率卖在低点 |
| 持续僵持（1到6个月） | 市场逐步消化，波动回落 | 可分批定投被错杀的优质标的 |

| 冲突缓和/停火 | 风险资产反弹 | 提前布局，不等停火公告才行动 |

| 原则 | 说明 |
|-----|------|

## 美元周期与 QDII 汇率双重效应

> QDII 投资者的实际收益 = 标的资产涨跌 + 汇率涨跌。美元走强时 QDII 净值被放大，走弱时被压缩。这层效应经常被忽视。

### 汇率对 QDII 净值的影响

| 场景 | 标的涨跌 | USD/CNY 变化 | QDII 净值表现 | 实际收益 |
|-----|---------|-------------|------------|---------|
| 双重利好 | 美股涨 +5% | 美元升值 +2% | 净值涨约 +7% | 超预期 |
| 涨跌对冲 | 美股涨 +5% | 美元贬值 -3% | 净值涨约 +2% | 低于预期 |
| 双重利空 | 美股跌 -5% | 美元贬值 -2% | 净值跌约 -7% | 双杀 |
| 对冲保护 | 美股跌 -5% | 美元升值 +3% | 净值跌约 -2% | 汇率缓冲 |

### 判断美元走向

| 信号 | 美元走强 | 美元走弱 |
|-----|---------|---------|
| 美联储政策 | 维持高利率或加息 | 降息或暗示降息 |
| 美国经济 | 相对强劲 | 衰退迹象 |
| 避险需求 | 全球动荡，资金涌入美元 | 风险偏好回升 |
| 财政状况 | 赤字可控 | 赤字急剧扩大，债务担忧 |

```
搜索词：
"US dollar index DXY current level 2026"
"USD CNY exchange rate forecast 2026"
```

### 对持仓的操作指引

- **美元强势期**：QDII 净值有汇率加成，不急于加仓（避免买在汇率高点）；如要新建仓位，优先选择有汇率对冲（人民币份额 H 类）的基金
- **美元弱势期**：QDII 净值受汇率拖累，但若标的资产基本面好，反而是加仓好时机（汇率贬值 = 买入成本低）
- **每次报告须注明**：当前 USD/CNY 汇率、美元指数 DXY 水平、与半年前相比的趋势方向

## QDII 基金特殊风险

> 以下风险为 QDII 独有，普通 A 股基金不存在，分析时需额外关注。

| 风险 | 说明 | 对操作的影响 |
|-----|------|-----------|
| QDII 额度耗尽 | 基金公司外汇额度用完，暂停申购 | 想买买不进，需关注基金公告 |
| 大额限购 | 单日申购上限（常见 500到1000元） | 大资金无法一次性建仓，需分多日多基金 |
| 净值滞后 | QDII 净值 T+2 才公布（比 A 股基金晚 1 天） | 决策时看到的净值是前天的，实际买入价未知 |
| 赎回到账慢 | T+7 到 T+10 才到账（A 股基金 T+1 到 T+3） | 急需用钱时流动性差，不能将 QDII 当作应急资金 |
| 汇率结算延迟 | 申购和赎回分别按不同日汇率折算 | 短期交易汇率损耗大，适合中长期持有 |

## 量化风险管理框架

> 本节为量化分析规范，在 SKILL Step 0.5 中使用，为报告提供数字化风险测量，非主观判断。

### 组合集中度量化：HHI 与 Effective N

**计算方法（从快照数据推算）：**

```
Step 1: 合并同指数基金
  将跟踪同一指数（如纳斯达克100、标普500）的多只基金市值合并为一个"策略"。
  同指数判断依据：基金名称中含「纳斯达克」「标普500」「NASDAQ」「S&P 500」等关键词。

Step 2: 计算策略权重
  strategy_weight_i = strategy_market_value_i / total_fund_assets  (不含活期宝)

Step 3: 计算 HHI（赫芬达尔-赫希曼指数）
  HHI = Σ(strategy_weight_i²)
  HHI 取值范围：0（完全分散）到 1（完全集中于单一策略）

Step 4: 计算有效持仓数 Effective N
  N_eff = 1 / HHI
  含义：等价于持有 N_eff 只权重相等的独立策略
```

**解读标准：**

| N_eff | HHI | 风险评级 | 说明 |
|-------|-----|---------|------|
| < 3 | > 0.33 | 🔴 高度集中 | 单一策略主导，系统性冲击将重创全组合 |
| 3 到 5 | 0.20 到 0.33 | 🟡 中度集中 | 有分散但不足，新资金引导分散 |
| > 5 | < 0.20 | 🟢 合理分散 | 达标，保持现状 |

### 情景压力测试（Scenario Stress Test）

> 每次报告必须计算以下三种情景的估算影响。数据来自快照持仓，详细结果列入报告「六、组合量化指标 6.3」，摘要结论（最大损失金额和占比）同步写入「八、量化风险摘要」的「情景最大压力」行。

**三大压力情景：**

| 情景 | 假设冲击 | 影响估算公式 |
|------|---------|------------|
| S1：美股科技回调 | 纳斯达克100 下跌 20% | 冲击额 = 纳斯达克策略总市值 × (-20%) |
| S2：汇率双杀 | USD/CNY 贬值 5%（人民币升值） | 冲击额 = 全部QDII总市值 × (-5%) |
| S3：综合压力 | S1 + S2 同时发生（2022年复现概率约15%） | 冲击额 = S1冲击 + S2冲击（简化，忽略相关性） |

**说明：**
- 这是"一阶近似"估算，忽略持仓内的对冲效应和标的间相关性，偏保守（结果偏悲观）
- 目的是让用户直观感受极端情景下的账面亏损规模，而非精确预测
- 计算结果以"绝对金额"列示（如 -X万元），并换算为家庭总资产的百分比

**在报告中的写法示例：**
```
| 情景 | 假设 | 估算冲击额 | 占家庭总资产 |
|------|------|---------|------------|
| S1 美股-20% | 纳斯达克策略 X万元 × 20% | -X万元 | -X% |
| S2 汇率-5% | QDII合计 X万元 × 5%  | -X万元 | -X% |
| S3 综合压力 | S1+S2叠加 | -X万元 | -X% |
```

### 技术入场过滤（200日均线 + 动量确认）

> **适用范围：仅适用于 QDII 境外市场（日本、韩国、德国、印度、欧洲等）。**
> **不适用于 A股**：A股散户占主导，存在反转效应而非动量效应，学术实证表明 A股动量策略有效性显著低于成熟市场。A股入场应使用 `investment-preferences.md` 第四节「A股加仓前提条件」框架，而非技术过滤。
>
> 估值（PE）判断"贵不贵"；技术趋势判断"涨不涨"。两者结合才是专业入场标准。
> **规则：对于新建仓的 QDII 境外市场（首次买入或重启暂停定投），技术过滤是入场的必要条件，而非可选项。**

#### 200日均线（趋势过滤）

| 状态 | 含义 | 操作含义 |
|------|------|---------|
| 指数 > 200日MA | 长期上升趋势 | 可以入场（结合估值判断） |
| 指数 < 200日MA | 长期下降趋势 | 不建议新建仓；已持有的不追加 |
| 指数 刚穿越200日MA（上穿） | 趋势转换信号 | 可小额试探性建仓 |

**搜索词：**
```
"Nikkei 225 200-day moving average YYYY"
"KOSPI 200 day MA current YYYY"
"DAX 200 moving average YYYY"
"Nifty 50 200 day moving average YYYY"
```

#### 动量过滤（6个月 + 12个月）

> 动量是已被学术证实的股票市场因子（Jegadeesh & Titman, 1993）。正动量市场中长期持有胜率更高。

| 动量信号 | 条件 | 操作含义 |
|---------|------|---------|
| 双正动量 🟢 | 6M涨幅 > 0 且 12M涨幅 > 0 | 趋势健康，可积极布局 |
| 单正动量 🟡 | 6M 或 12M 之一为正 | 可小仓位入场，注意止损 |
| 双负动量 🔴 | 6M涨幅 < 0 且 12M涨幅 < 0 | 下跌趋势明确，等待趋势反转再买 |

**搜索词：**
```
"Nikkei 225 6 month 12 month performance return YYYY"
"KOSPI index 6-month 12-month return YYYY"
"DAX index 6-month 1-year performance YYYY"
```

#### 技术 + 估值联合判断矩阵

| 估值 \ 技术趋势 | 上升趋势（指数>200MA） | 下降趋势（指数<200MA） |
|--------------|-------------------|-------------------|
| 低估（PE<历史中位） | 🟢 最优入场时机，积极建仓 | 🟡 估值吸引但趋势不对，小额月定投等待趋势反转 |
| 合理（PE在历史中位附近） | 🟡 可以入场，月定投为主 | 🔴 暂不入场，等待趋势确认 |
| 高估（PE>历史中位+30%） | 🔴 不追高，高位高趋势双重警示 | 🔴 回避 |

### 仓位定量计算框架（Position Sizing）

> 华尔街标准：每次买入建议必须基于"目标权重缺口"而非凭感觉给金额。

**计算步骤：**

```
Step 1: 确认目标权重（来自 investment-preferences.md 第五节）
  target_weight_i = 目标配置中该策略的权重（如日本QDII目标7.5%，取中间值）

Step 2: 计算当前权重
  current_weight_i = 该策略当前市值 / 家庭总基金资产

Step 3: 计算权重缺口
  gap_i = target_weight_i - current_weight_i
  若 gap > 0：低配，可买入
  若 gap < 0：超配，停止新增

Step 4: 计算本期建议买入额（分批原则）
  本期买入额 = 家庭总基金资产 × gap_i × 填补比例
  首次建仓填补比例：30%（先试仓）
  已有持仓填补比例：50%（已确认逻辑，可以加快）
  市场信号绿灯时最高：70%（趋势+估值双确认时加速）
```

**在报告行动指令中的标准写法：**

```markdown
✅ 买入 摩根日本精选股票（007280），建议 X,XXX 元
   权重缺口：目标 7.5%，当前 0%，本期填补 30% = X,XXX元
   估值：Nikkei今日 XX,XXX点，PE约XX（历史中位以下）
   趋势：指数在200日均线上方，6M/12M动量均正
```

### 费用拖累分析（Fee Drag）

> QDII 基金管理费通常高于普通A股基金（0.8到1.5%/年），多基金持仓还会产生隐性成本。

**需关注的费率问题：**

| 问题 | 说明 | 建议 |
|------|------|------|
| 跟踪同一指数的基金只数过多 | 多持3只跟踪纳斯达克100的基金 vs 持1只，收益差别不大但管理复杂度增加 | 建议聚焦1到2只流动性最好、规模最大的标的 |
| 高费率 vs 低费率 | 部分QDII年管理费1.5%，低费率产品可能只有0.8% | 在同质标的中优先选低费率 |
| QDII 申购赎回费 | 部分基金申购费1到1.5%（即使打折后0.1到0.15%），频繁买卖损耗大 | 定投 > 单次大额买入的费用效率 |

**费率影响估算（10年复利）：**
- 每年多支付0.5%费率，10年后净值少约4.9%（复利累积）
- 家庭总QDII 50万元时，费率差0.5%/年 = 每年多付2,500元

### 再平衡触发规则

> 再平衡不是每次报告都要做，是当偏差超过阈值时才触发。

**触发条件（满足任意一条即触发）：**

| 触发条件 | 说明 | 处理方式 |
|---------|------|---------|
| 某策略权重超标超过 10 个百分点 | 如目标40%，当前实际 > 50% | 停止该策略所有新增；新资金全部流向低配策略 |
| 防御仓位（债券+货币）低于 8% | 流动性底线临近 | 下次新增资金优先补债券/活期宝至10%以上 |
| 某账户权益占比超过个人风险偏好上限 | 如妈妈账户权益 > 30% | 停止妈妈账户权益买入；**但需先查阅 `investment-preferences.md` 账户专属策略**——若该账户配置为"历史遗留不触发强制再平衡"，则仅停止新增，不主动赎回 |
| N_eff < 3 | 极度集中 | 新资金100%引导至空白类别，直到N_eff > 4 |

**不触发再平衡的情况（避免过度操作）：**
- 某策略因市场上涨而偶然超配，但未超出 +10个百分点偏差
- 短期市场波动导致的权重漂移（正常范围内的波动不操作）
- 持仓逻辑完整，只是权重略微偏离目标（继续持有，靠新资金自然调整）
