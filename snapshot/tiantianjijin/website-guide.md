# 天天基金网站结构指南

## 说明

本文档描述天天基金交易网站（trade.1234567.com.cn）的页面结构，供采集 skill 参考。账户姓名从页面动态读取，不在此硬编码。

- 登录 URL: 登录态失效时可能跳转到 `https://passport.1234567.com.cn/` 或 `https://login.1234567.com.cn/`，两者均视为需重新登录。

## 页面结构

### 主页（资产概况）

URL: `https://trade.1234567.com.cn/MyAssets/Default`

**左侧导航菜单**（按此导航，不要用卡片快捷按钮）:
- 我的资产（展开）
  - 我的持仓 → 持仓明细页
  - 我的活期宝 → 活期宝详情
- 基金交易（展开）
  - 买基金 ⚠️ 交易操作，不要点
  - 卖基金 ⚠️ 交易操作，不要点
  - 基金转换 ⚠️ 交易操作，不要点
  - 基金定投 → 点击后展开子菜单，包含「定投计划」（查看用，入口名为「定投计划」而非「我的定投计划」）、「新增定投」⚠️（勿点）
  - 交易查询 ✅ 可用于查看历史交易
- 账户管理

**主页卡片区域**（仅用于读数，不要点击卡片内快捷操作）:

| 卡片 | 显示内容 | 快捷操作（勿点） |
|-----|---------|---------------|
| 活期宝 | 余额、每日收益 | 充值、取现、买基金 |
| 基金资产 | 总额、持仓收益、累计收益 | 买基金、**持仓**、卖出、转换 |
| 投顾资产 | 总额、累计收益 | 详情（App only） |
| 养老资产 | 总额、累计收益 | 详情（App only） |

⚠️ **已知陷阱 1**: 基金资产卡片内有一个「持仓」快捷链接（在「买基金 持仓 | 卖出 | 转换 | 交易查询」行内），这个虽然名为「持仓」但混在交易操作中，**可能误操作**。查看持仓应使用左侧导航的「我的持仓」。

⚠️ **已知陷阱 2**: 基金资产卡片内的「查看定投计划」快捷链接是 JS 触发，实测点击后不会完成跳转（snapshot 仍停留在主页）。**查看定投计划必须使用左侧导航「基金定投」→「定投计划」**，点击后页面内容区会切换显示定投计划，不跳转新页面。

### 持仓明细页

URL: `https://trade.1234567.com.cn/myAssets/hold`（需从主页导航进入）

**页面结构**:
- Tab 切换：基金 | 活期宝 | 高端理财 | 投顾资产
- 汇总数据：
  - 活期宝余额及当日收益
  - 基金总额 / 持仓收益 / 累计收益
- 每只基金一条记录，格式：
  ```
  [基金名称（代码）] [类型] | 最新净值：X.XXXX（MM-DD）
  [市值数字] [有在途交易（可选）]
  [收益金额] [收益率%]
  [买入] [卖出] [明细]  ← 操作按钮，勿点
  ```
- 页面底部有「下载持仓数据」按钮（可用）

**在途交易**: 部分基金会显示「有在途交易」，表示有未完成的申购或赎回，该基金市值可能不准确。

**净值日期**: QDII 基金净值日期通常比 A 股基金晚 1 天（因为美股收盘时间不同）。

## 持仓数据解读

### 基金类型含义

| 类型 | 含义 | 代表风险 |
|-----|------|---------|
| QDII | 投资境外市场的人民币基金，受外汇汇率影响 | 高（含汇率风险） |
| 股票型 | 主要投资A股股票 | 高 |
| 混合型 | 股票+债券混合 | 中高 |
| 指数型 | 跟踪特定指数 | 中高 |
| 债券型 | 主要投资债券 | 中低 |
| 货币型 | 货币市场工具 | 低 |

### 持仓收益 vs 累计收益

- **持仓收益**: 当前持有份额的浮动盈亏（市值 - 当前持仓成本）
- **累计收益**: 包含历史已卖出部分的已实现收益 + 当前浮动收益

### 市值与在途

- **市值（不包括在途）**: 已确认份额按最新净值计算的价值
- **有在途交易**: 有申购中的资金（已扣款但份额未到账）或赎回中的份额（份额已扣但钱未到账）

## 登录失效处理

如果 `browser_navigate` 到主页后，`browser_snapshot` 显示：
- URL 变为 `passport.1234567.com.cn/...` 或 `login.1234567.com.cn/...` → 需要重新登录
- 页面 title 含「登录」→ 需要重新登录
- 页面出现「请登录」或「登录超时」提示 → 需要重新登录

**此时停止所有操作，告知用户**：「天天基金的登录状态已过期，请在 Cursor 内置浏览器中打开 https://trade.1234567.com.cn/MyAssets/Default 重新登录，完成后告知我继续采集。」

**不要尝试自动登录**（涉及密码安全）。

## 多账户切换说明

账户切换由用户在浏览器中自行完成（退出 → 扫码登录下一个账号）。AI 不主动操作退出，等用户告知后，重新 navigate 到主页确认新账户姓名即可。

## JSON Schema 字段说明

| 字段 | 说明 |
|-----|------|
| `snapshot_time` | ISO 8601，北京时间（+08:00），以首个账户写入时间为准 |
| `accounts[].alias` | 账户称呼（如「本人」「妈妈」），用户未提及则留空字符串 |
| `overview.cash_fund_daily_income` | 优先用持仓明细页精确值（4位小数），其次用主页显示值 |
| `holdings[].holding_income_rate` | 百分比数字，不含 % 符号（如 40.67 代表 40.67%）|
| `holdings[].in_transit` | 是否有「有在途交易」标识 |
| `holdings[].market_value` | 「不包括在途」的市值 |
| `drip_plans[].type` | `"普通定投"` / `"活期宝定期充值"` / `"智能定投"` |
| `drip_plans[].amount` | 每期金额（元，数字） |
| `drip_plans[].frequency` | `"每日"` / `"每周"` / `"每月"`（页面若为「每日(交易日)」可存为「每日」） |
| `drip_plans[].deduct_day` | 扣款日，如 `"每月10日"` / `"1日"`（每月1号）/ `"每周一"` / `"--"`（每日无固定日） |
| `drip_plans[].status` | `"正常"` / `"暂停"` / `"已终止"` |
| `watchlists` | 自选基金（按通行证账户分组），跳过时为 `[]` |
| `watchlists[].passport_account` | 通行证账户名（从自选区域读取，非顶部导航） |
| `watchlists[].funds[].daily_growth_value` | 日增长值（元，数字） |
| `watchlists[].funds[].daily_growth_rate` | 日增长率（%，存数字如 0.27，不含 % 符号） |
| `watchlists[].funds[].since_inception_rate` | 成立以来涨幅（%，存数字如 84.67，不含 % 符号） |
| `watchlists[].funds[].max_purchase_per_day` | 单日申购限额（字符串，如 `"500元"` `"--"` `"100万元"` `"0元"`） |
| `watchlists[].funds[].purchase_status` | 申购状态列文字：`"开放申购"` / `"暂停申购"` / `"限大额"` / `"场内交易"` 等 |
| `watchlists[].funds[].can_purchase` | 购买按钮颜色：橙色=`true`，灰色=`false`（与 purchase_status 互为补充）|
